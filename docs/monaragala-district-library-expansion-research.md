# Monaragala District Library Expansion and Readiness Research

## 1. Purpose

### 1.1 Objective

Research the Monaragala District public-library landscape so the Sevanagala Smart Library project can later evaluate realistic expansion opportunities without assuming that every library has the same technology, data quality, staff capacity, or institutional readiness.

This document is an expansion research record. It does not commit the project to a district-wide rollout.

## 2. Evidence Rules

### 2.1 Date Every Claim

Library grades, software status, websites, staff, book counts, and digital-service status can change.

Record the source date and do not merge older and newer facts as if they were simultaneous.

### 2.2 Prefer Official Sources

Priority order:

1. National Library and Documentation Services Board;
2. Provincial / local-authority library sources;
3. library's own public catalogue/site;
4. ICTA or other responsible public-sector programme sources;
5. third-party directories only as discovery leads.

### 2.3 Record Conflicts

If two reliable sources disagree, record both with dates and mark the current state as requiring verification.

## 3. National Context

### 3.1 Public Library Scale

The National Library and Documentation Services Board's 2025 statistics report lists 1,284 public libraries in Sri Lanka.

This is a useful long-term market/service-context figure, not a deployment target.

### 3.2 Expansion Principle

The project should not design for all 1,284 libraries at once.

Recommended evidence-driven path:

Sevanagala → nearby / same-authority libraries → selected Monaragala pilots → district model → wider replication.

## 5. Source Conflict Example

### 5.1 Bibile

The 2022/23 National Library graded list records Bibile Public Library as Grade III.

The currently accessible Bibile OPAC page states that Bibile is now a Grade II library.

### 5.2 Implication

The project must store time-sensitive institutional facts with:

- source;
- observed/verified date;
- status;
- optional notes.

Do not hard-code library grade into software without a current verification process.

- Sevanagala Public Library — Grade III;
- Kalwelgala Public Library — Grade III.

### 6.2 Thanamalvila Public Library Public Evidence

The reviewed public library site describes:

- lending services;
- returns;
- membership;
- children's section;
- reference section;
- study section;
- newspaper and magazine services;
- local information activities;
- reader-promotion programmes;
- inter-library transfer of books to Kalwelgala branch.

### 6.3 Expansion Opportunity

Because Sevanagala, Thanamalvila, and Kalwelgala fall under the same local authority in the official graded list, this cluster may become an especially useful later test case for:

- shared configuration;
- cross-library discovery;
- branch/holding models;
- inter-library requests;
- shared staff training;
- common reporting.

This remains a research hypothesis until institutional workflows and authority are confirmed.

## 7. Bibile Digital Readiness Signal

### 7.1 Current Public OPAC

Bibile has a functioning Koha public catalogue and states that the Digital Libraries Project was implemented in 2021.

Its public OPAC exposes or describes:

- search;
- find;
- locate;
- hold;
- membership application;
- rules;
- opening hours;
- contact information;
- multiple library service sections.

### 7.2 Metadata Evidence

A reviewed Bibile MARC record exposes copy-level data such as:

- collection;
- permanent/current location;
- shelving location;
- date acquired;
- call number;
- barcode;
- item type.

### 7.3 Sevanagala Lesson

A district-scale platform cannot assume that all libraries need the same migration strategy.

Some libraries may already have rich Koha item data and need a modern integration/discovery layer rather than a replacement database.

### 8.1 Monaragala, Buttala and Wellawaya

- Monaragala Pradeshiya Sabha;
- Buttala Pradeshiya Sabha;

### 8.2 Research Rule

A web page existing does not equal digital-library readiness.

Readiness must separately assess:

- current catalogue;
- staff workflow;
- reliable book/copy data;
- internet;
- devices;
- authentication;
- privacy/security;
- online member services;
- support/maintenance capacity.

## 9. District Readiness Framework

### 9.1 Capability Levels

Use a practical readiness model.

#### Level A — Basic Public Presence

- verified library profile;
- hours;
- contact;
- services;
- announcements.

#### Level B — Digital Catalogue Ready

- cleaned bibliographic records;
- reliable copy records;
- shelf/location data;
- search.

#### Level C — Integrated Library Services

- Koha/LMS or equivalent;
- circulation;
- member records;
- holds/renewals;
- live availability;
- staff workflow.

#### Level D — Smart Library Layer

- modern discovery UX;
- multilingual search;
- notifications;
- digital membership services;
- analytics;
- events;
- digital resources.

#### Level E — Network Ready

- stable library identifiers;
- cross-library holdings;
- integration APIs;
- inter-library workflow;
- shared standards;
- network governance.

A higher grade does not automatically mean a higher digital-readiness level.

## 11. Rollout Decision Criteria

### 11.1 Do Not Select Only by Library Grade

Pilot selection should consider:

- institutional willingness;
- staff ownership;
- data readiness;
- technical compatibility;
- community value;
- support capacity;
- ability to measure outcomes.

### 11.2 Sevanagala as Reference Deployment

Before expanding, document at Sevanagala:

- implementation effort;
- collection cleanup effort;
- staff training hours;
- support issues;
- user adoption;
- search usage;
- circulation integration reliability;
- accessibility findings;
- recurring cost;
- operational improvements.

These become evidence for later district proposals.

## 12. Research Gaps

### 12.1 Current District Count

The 2022/23 graded list confirms 24 graded Monaragala District entries, but a current 2026 district-wide total including ungraded libraries still requires verification from up-to-date official statistics.

### 12.2 Current Grades

Re-verify current grades, especially where newer library sites conflict with the 2022/23 list.

### 12.3 Automation Status

Systematically verify for each district library:

- Koha;
- another LMS;
- spreadsheet/manual;
- public OPAC;
- no public evidence.

### 12.4 Digital Libraries Project

Map which Monaragala District libraries participated in ICTA/NLDSB digital-library initiatives.
